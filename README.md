# Healthy Habits — трекер здоровых привычек

Пять небольших шагов для заботы о себе каждый день. React, Vite и обычный CSS. Без аккаунтов, сервера и платных сервисов.

## Как открыть сайт

1. Установите Node.js 22, если его ещё нет.
2. Откройте терминал в папке проекта.
3. Выполните `npm ci`.
4. Выполните `npm run dev`.
5. Откройте адрес, который появится в терминале (обычно http://localhost:5173).

## Как проверить

Отметьте привычку: счётчик и круг покажут 20%. Обновите страницу: отметка сохранится. Повторное нажатие снимает её. Отметьте все пять: появится поздравление.

Отметки хранятся в браузере отдельно для каждой местной календарной даты. Новый день начинается с пустого списка, предыдущие данные остаются. Между устройствами данные не переносятся. Очистка данных браузера удаляет результаты. При недоступном хранилище сайт покажет предупреждение.

- `npm test` — проверка сохранения, дат и отдельных результатов за разные дни.
- `npm run build` — сборка готового сайта в папку `dist`.
- `npm run preview` — локальная проверка собранного сайта.

## Какие файлы за что отвечают

- `index.html` — основа страницы и её название.
- `src/main.jsx` — интерфейс, привычки и круг прогресса.
- `src/style.css` — цвета, карточки и оформление для телефона.
- `src/storage.js` — сохранение отметок по дням.
- `src/storage.test.js` — проверки сохранения.
- `package.json` и `package-lock.json` — зависимости и команды проекта.
- `netlify.toml` — готовые настройки Netlify.
- `.gitignore` — исключает зависимости и сборку из Git.

## Публикация на Netlify

Проект подготовлен, но автоматически не публикуется.

После вашего решения опубликовать:

1. Загрузите файлы проекта в GitHub.
2. В Netlify выберите добавление проекта из GitHub.
3. Выберите репозиторий `healthy-habits`.
4. Проверьте команду сборки `npm run build` и папку результата `dist`.
5. Запустите публикацию.

Ключи и переменные окружения не нужны. Настройки уже записаны в `netlify.toml`.
