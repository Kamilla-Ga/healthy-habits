# Healthy Habits — трекер здоровых привычек

Пять небольших шагов для заботы о себе каждый день. React, Vite и обычный CSS. Без аккаунтов, сервера и платных сервисов.

## Как открыть сайт

1. Установите Node.js 22, если его ещё нет.
2. Откройте терминал в папке проекта.
3. Выполните `npm ci`.
4. Выполните `npm run dev`.
5. Откройте адрес, который появится в терминале (обычно http://localhost:5173).

## Как проверить

Отметьте привычку: счётчик и круг покажут 20%. Обновите страницу: отметка сохранится. Повторное нажатие снимает её. Отметьте все пять: появится поздравление.

Отметки хранятся в браузере отдельно для каждой местной календарной даты. Новый день начинается с пустого списка, предыдущие данные остаются. Между устройствами данные не переносятся. Очистка данных браузера удаляет результаты. При недоступном хранилище сайт покажет предупреждение.

- `npm test` — проверка сохранения, дат и отдельных результатов за разные дни.
- `npm run build` — сборка готового сайта в папку `dist`.
- `npm run preview` — локальная проверка собранного сайта.

## Какие файлы за что отвечают

- `index.html` — основа страницы и её название.
- `src/main.jsx` — интерфейс, привычки и круг прогресса.
- `src/style.css` — цвета, карточки и оформление для телефона.
- `src/storage.js` — сохранение отметок по дням.
- `src/storage.test.js` — проверки сохранения.
- `package.json` и `package-lock.json` — зависимости и команды проекта.
- `netlify.toml` — готовые настройки Netlify.
- `.gitignore` — исключает зависимости и сборку из Git.

## Публикация на Netlify

Проект подготовлен, но автоматически не публикуется.

После вашего решения опубликовать:

1. Загрузите файлы проекта в GitHub.
2. В Netlify выберите добавление проекта из GitHub.
3. Выберите репозиторий `healthy-habits`.
4. Проверьте команду сборки `npm run build` и папку результата `dist`.
5. Запустите публикацию.

Ключи и переменные окружения не нужны. Настройки уже записаны в `netlify.toml`.

## Версия 2: календарь и личный дневник

- «Мой день»: вводите стаканы воды, часы сна и часы активности/обучения. Достижение цели отмечает привычку автоматически; галочку также можно поставить или снять вручную.
- «Календарь»: переключайте месяцы, выбирайте прошлую дату и просматривайте или дополняйте записи. Будущие даты недоступны. День без записи не считается неудачным.
- «Мои итоги»: последние семь календарных дней, выполненные привычки и средние введённые значения. Значения без измерений не подменяются нулями.
- «Профиль и цели»: имя, фамилия, личная цель, ежедневные ориентиры и добавление своих привычек (до 30 всего).
- Для каждого дня можно выбрать настроение и сохранить заметку.
- «Скачать мои данные» сохраняет JSON-копию. «Загрузить резервную копию» восстанавливает данные, сохраняя существующие записи совпадающих дней. Профиль и цели берутся из копии.

Старые отметки первой версии читаются автоматически. Они остаются в исходном хранилище, а новые записи сохраняются отдельно под ключом `healthy-habits:v2`. Новые привычки не добавляются в уже записанные прошлые дни. Изменение цели не пересчитывает сохранённые галочки.

`src/model.js` отвечает за дневник, перенос старых данных и расчёт итогов; `src/model.test.js` проверяет эти функции. Для подробного отчёта проверок: `node src/model.test.js` и `node src/storage.test.js`.

Все данные, включая имя и заметки, остаются в браузере. Копия содержит личные записи: не загружайте её в GitHub. Автоматической синхронизации между устройствами нет.

Активность и обучение учитываются в часах, включая дробные значения (например, 0.5 или 1.5). Ранее сохранённые минуты и цели автоматически переводятся в часы, в том числе при загрузке старой резервной копии. Галочки и заметки сохраняются.

## Литры, виды активности и дневные планы

Вода вводится в литрах (например, 1.5). Старые стаканы пересчитываются по условному объёму 250 мл; подсказка предлагает проверить цель и историю. Повторное открытие или импорт уже пересчитанной копии не меняет объём второй раз.

В активности можно выбрать несколько вариантов (пилатес, плавание, йога, бег и другие) или вписать свои. Продолжительность — суммарные часы за день.

Skincare разделён на утреннюю и вечернюю рутину; общая привычка выполнена после обеих отметок. Старые общие отметки сохраняются отдельно: приложение не придумывает время ранее выполненного ухода.

В каждом дне доступны цели и три поля итогов: что получилось, что не получилось и что сделано сверх плана. Все поля доступны через календарь и входят в резервную копию.

Медитация и чтение книг добавлены отдельными привычками. Медитация отмечается одной галочкой, без времени и числовой цели. Начальная цель чтения — 0.5 часа; её можно изменить в профиле. Они появляются с текущего дня, не меняя состав и результаты прошлых дней. Время включается в недельные итоги.

## Личный набор привычек

При первом открытии на новом браузере пользователь вводит имя, фамилию и год рождения и выбирает минимум одну привычку из каталога (23 занятия). На главной странице будут только выбранные привычки. Год рождения сохраняется локально и не используется для медицинских рекомендаций.

В «Профиль и цели» можно изменить данные и набор, затем нажать «Сохранить профиль и привычки». Изменения применяются к сегодняшнему и последующим дням; состав прошлых записей остаётся прежним. При отключении привычки её отметка за сегодня сохраняется в архиве и восстанавливается при повторном включении. Измерения, заметки и профиль входят в резервную копию. Пользователи прежней версии сохраняют существующий набор без повторного первого входа.

Новый знак Healthy Habits — ботаническая эмблема с листочками, нарисованная SVG; внешние шрифты и сервисы для неё не нужны.
